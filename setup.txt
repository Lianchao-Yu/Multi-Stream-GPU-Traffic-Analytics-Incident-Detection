- Driver Version >= 580（建议 R620+）

如果驱动仍低于 580，或 CUDA Version 仍显示 12.x：
- **停止执行**

- 不要继续 CUDA 13 安装

### 4. 配置环境变量

把以下内容幂等地写入 `~/.bashrc`（先检查是否已有相同行，避免重复）：

```bash

export LD_LIBRARY_PATH="$CUDA_HOME/lib64:$LD_LIBRARY_PATH"
```

然后：


如果 `which nvcc` 仍指向 `/usr/bin/nvcc`（Ubuntu 12.4）：

- 不要直接删除系统 CUDA 包，除非用户明确同意
- 后续 CMake 显式设置 `CUDAToolkit_ROOT=/usr/local/cuda-13.5`

确认目录内容：

检查动态库依赖是否缺失：

```bash
ldd "$ONNXRUNTIME_ROOT/lib/libonnxruntime_providers_cuda.so" | grep "not found" || echo "no missing deps"
ldd "$ONNXRUNTIME_ROOT/lib/libonnxruntime.so" | grep "not found" || echo "no missing deps"
```

如果出现 `not found`，保留完整输出，停止并报告，不要继续硬跑。

### 9. ONNX Runtime CUDA EP Smoke Test

#### 9.1 生成 tiny ONNX 模型

用 Python `onnx.helper` 生成一个很小的 Conv 或 MatMul 模型，保存到：

```text
/tmp/opencode/planB_smoke/tiny.onnx
```

推荐生成一个 `1x3x32x32` 输入的 Conv 模型，这样可以同时验证 CUDA 和 cuDNN。

#### 9.2 写 C++ ORT 测试

C++ 程序要求：

- `Ort::GetAvailableProviders()`，打印所有 provider，确认包含 `CUDAExecutionProvider`
- 创建 `Ort::SessionOptions`
- 用 `SessionOptionsAppendExecutionProvider_CUDA` 或 C++ API 的 `AppendExecutionProvider_CUDA` 启用 device 0
- 设置 `ORT_LOGGING_LEVEL_VERBOSE`，便于确认节点是否被 CUDA EP 接管
- 加载 `tiny.onnx`
- 构造输入并运行一次
- 打印输出维度/前几个值

编译时确保：

```bash
-I"$ONNXRUNTIME_ROOT/include"
-L"$ONNXRUNTIME_ROOT/lib" -lonnxruntime
-Wl,-rpath,"$ONNXRUNTIME_ROOT/lib"
```

运行前确认：

```bash
export LD_LIBRARY_PATH="$ONNXRUNTIME_ROOT/lib:$CUDA_HOME/lib64:$LD_LIBRARY_PATH"
```

验收：

- `GetAvailableProviders()` 包含 `CUDAExecutionProvider`
- Session 能成功创建并运行
- 日志中没有未记录的 CPU fallback 关键告警
- 如果 cuDNN / CUDA 库加载失败，保留完整错误并停止

### 10. CMake + Ninja + CUDA + ORT + OpenCV 工具链 Smoke Test

在 `/tmp/opencode/planB_smoke/cmake_test/` 建一个临时 CMake 工程：

```cmake
cmake_minimum_required(VERSION 3.24)
project(planb_smoke LANGUAGES CXX CUDA)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

find_package(CUDAToolkit REQUIRED)
find_package(OpenCV REQUIRED)

find_package(PkgConfig REQUIRED)
pkg_check_modules(FFMPEG REQUIRED libavformat libavcodec libavutil libswscale)

add_executable(planb_smoke main.cpp)
target_include_directories(planb_smoke PRIVATE
  ${ONNXRUNTIME_ROOT}/include
  ${FFMPEG_INCLUDE_DIRS}
  ${OpenCV_INCLUDE_DIRS}
)
target_link_directories(planb_smoke PRIVATE ${ONNXRUNTIME_ROOT}/lib)
target_link_libraries(planb_smoke PRIVATE
  onnxruntime
  ${OpenCV_LIBS}
  ${FFMPEG_LIBRARIES}
  CUDA::cudart
)
```

`main.cpp` 做最小验证：

- 打印 `cv::getBuildInformation()` 里的版本
- 打印 FFmpeg 版本
- 打印 `Ort::GetAvailableProviders()`
- 可选：运行 tiny.onnx

构建：

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CUDA_ARCHITECTURES=89 \
  -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build build -j
./build/planb_smoke
```

注意：

- 如果 `find_package(CUDAToolkit)` 找到的是 12.4，显式传 `-DCUDAToolkit_ROOT=/usr/local/cuda-13.5`
- 不要把正式 `CMakeLists.txt` 写进项目根目录，这一步只在临时目录验证工具链
